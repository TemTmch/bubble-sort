# Настройка Supabase для Bubble Sort

Делается один раз, примерно 10 минут. Всё — в панели проекта на supabase.com.

## 1. Создать таблицы и правила доступа

1. Слева **SQL Editor** → **New query**.
2. Скопируйте весь файл [`schema.sql`](./schema.sql) и вставьте в редактор.
3. Нажмите **Run**. Внизу должно появиться «Success. No rows returned».

Файл можно запускать повторно — он ничего не ломает и не удаляет данные.

## 2. Адрес сайта для писем со ссылкой

**Authentication** → **URL Configuration**:

- **Site URL:** `https://temtmch.github.io/bubble-sort/`
- **Redirect URLs** → **Add URL:** `https://temtmch.github.io/bubble-sort/`
  (для разработки на компьютере можно добавить ещё `http://localhost:5173/`)

Без этого ссылка из письма поведёт не на сайт.

## 3. Вход по почте и паролю

**Authentication** → **Sign In / Providers** → **Email**:

- **Enable Email provider** — включено;
- **Allow new users to sign up** — включено: учителя регистрируются сами;
- **Confirm email** — решите сами:
  - *включено* (надёжнее): после регистрации приходит письмо, без подтверждения войти нельзя.
    Но встроенная почта Supabase отправляет всего несколько писем в час на весь проект —
    если в один день регистрируется много учителей, часть писем задержится.
  - *выключено* (проще для запуска): учитель входит сразу после регистрации.
    Минус: можно зарегистрироваться с чужой почтой, не владея ею (данные других учителей это не открывает).
- **Minimum password length** — поставьте 8 (сайт и так требует не меньше 8).

Письмо «забыли пароль» тоже идёт через эту почту. Если писем станет не хватать —
подключим свой почтовый сервис (например, Resend — бесплатно до 3000 писем в месяц).

## 4. Регистрация открыта

Приглашений больше нет: любой, кто зарегистрировался (через Google или по почте и паролю),
получает своё отдельное пространство. Чужие наборы, классы и учеников он не видит.
**Первый зарегистрированный становится администратором** — он видит список учителей на сайте.

## 5. (Было) код в письме

Вход по ссылке и коду из письма больше не используется — шаг можно пропустить.

## 6. Обновление 002: общая библиотека и картинки

Если таблицы создавались раньше (до сентября 2026), выполните один раз:
**SQL Editor** → **New query** → вставьте весь файл [`002_library_images.sql`](./002_library_images.sql) → **Run**.
Появятся публичные и личные наборы, отправка набора коллегам и хранилище картинок `set-images`.
Для нового проекта это не нужно: всё уже есть в `schema.sql`.

## 7. Вход через Google

**А. Google Cloud** (console.cloud.google.com, любой Google-аккаунт):

1. Создайте проект (например, «Bubble Sort»).
2. **APIs & Services** → **OAuth consent screen**: тип **External**, название приложения, ваша почта; сохраните.
   Затем нажмите **Publish app** (иначе войти смогут только тестовые пользователи).
3. **APIs & Services** → **Credentials** → **Create credentials** → **OAuth client ID** → тип **Web application**:
   - **Authorized JavaScript origins:** `https://temtmch.github.io`
   - **Authorized redirect URIs:** `https://vcvcolnvuyjuuhuqhjoc.supabase.co/auth/v1/callback`
4. Скопируйте **Client ID** и **Client secret**.

**Б. Supabase:** **Authentication** → **Sign In / Providers** → **Google** → включить,
вставить Client ID и Client secret → **Save**.

Готово: на странице входа заработает кнопка «Войти через Google».
Учитель, вошедший через Google впервые, сразу получает своё пространство.

## 8. Обновление 003: регистрация без приглашений

Если база создавалась до октября 2026, выполните один раз:
**SQL Editor** → **New query** → вставьте весь файл [`003_open_signup.sql`](./003_open_signup.sql) → **Run**.
После этого каждая новая учётная запись сразу становится учителем, а набор коллеге отправляется по его почте
(список всех учителей сайта другим учителям больше не показывается).

## Ограничение бесплатного тарифа

Встроенная почта Supabase отправляет лишь несколько писем в час на весь проект.
Учителю письмо нужно редко: вход сохраняется на устройстве надолго.
Если писем станет не хватать, подключим свой почтовый сервис (например, Resend — бесплатно до 3000 писем в месяц).
